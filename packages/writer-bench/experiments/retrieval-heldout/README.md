# Held-out retrieval validation

This experiment evaluates the frozen narrative retriever on the synthetic Quiet Meridian corpus. Read [PREREGISTRATION.md](PREREGISTRATION.md) for the frozen system, allowed corrections, gates, and graduation rule.

The first deterministic and downstream results must be recorded whether they pass or fail. Quiet Meridian cannot become a retriever-development corpus until a different held-out corpus replaces it.
