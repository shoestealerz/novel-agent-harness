# Writer-aware memory and compaction

This experiment compares OpenCode's generic coding-session compaction schema with a writer-specific anchored memory. Both summaries are generated by the same model from the same session history. A second model call performs the downstream task using only the compacted summary.

Run the registered comparison:

```powershell
powershell -ExecutionPolicy Bypass -File .\experiments\writer-memory\run.ps1
```

See [PREREGISTRATION.md](PREREGISTRATION.md) for the fixed protocol and gates.
