# Integrated graduated-harness evaluation

This experiment compares raw DeepSeek, stock OpenCode, and the integrated retained writer mechanisms on identical scoped revision packets. Non-graduated mechanisms are disabled.

Run the three-trial evaluation and both comparisons:

```powershell
powershell -ExecutionPolicy Bypass -File .\experiments\integrated-harness\run.ps1
```

See [PREREGISTRATION.md](PREREGISTRATION.md) for the fixed inclusion list and gates.

The completed three-trial result is recorded in [RESULTS.md](RESULTS.md).
